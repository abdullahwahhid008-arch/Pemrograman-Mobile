# Pertemuan 4 — Pemrograman Mobile

Materi: Mengambil data dari REST API menggunakan HTTP, Async, dan FutureBuilder pada Flutter.

## Struktur folder
- `docs-tugas/` — dokumentasi tugas Pertemuan 4.
- `modul/` — simpan PDF modul praktikum Pertemuan 4 di sini.
- `praktikum4/` — simpan source code Flutter untuk latihan praktikum.
- `tugas4/` — simpan source code hasil tugas Daftar Postingan.

## Endpoint API
- Daftar postingan: `https://jsonplaceholder.typicode.com/posts`
- Komentar postingan: `https://jsonplaceholder.typicode.com/posts/{id}/comments`

Aplikasi tugas menampilkan daftar postingan, detail postingan, komentar, indikator loading, penanganan error, dan tombol coba lagi.
